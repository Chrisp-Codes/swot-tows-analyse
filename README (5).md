# Interaktive SWOT- und TOWS-Analyse

Eine kostenlose, einseitige Web-Anwendung für SWOT-Analysen mit anschließender TOWS-Ableitung (SO, WO, ST, WT).

## Funktionen

- SWOT-Matrix mit Stärken, Schwächen, Chancen und Risiken
- TOWS-Matrix mit Leitfragen zur strategischen Ableitung
- Beispiel laden zum Ausprobieren
- Speichern und Laden als JSON-Datei
- PDF-Export (A4 quer)
- Automatische Sicherung des aktuellen Entwurfs im eigenen Browser

## Nutzung

**Online:** Die Seite ist unter https://chrisp-codes.github.io/swot-tows-analyse/ erreichbar.

**Offline:** Die Datei `index.html` herunterladen und mit einem beliebigen modernen Browser öffnen. Eine Installation ist nicht nötig.

## Datenschutz

- Es gibt keinen Server, kein Konto, kein Tracking und keine Cookies.
- Eingaben bleiben im eigenen Browser (localStorage) bzw. in der exportierten JSON-Datei.
- Zum Erzeugen des PDFs wird beim Klick auf „PDF herunterladen“ die Bibliothek jsPDF von cdnjs.cloudflare.com geladen. Dabei wird die IP-Adresse an den CDN-Anbieter übermittelt. Wer das vermeiden möchte, kann den Druckdialog des Browsers nutzen.
